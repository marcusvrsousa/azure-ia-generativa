# Utilização de IA Generativa para extração de texto em imagem

🧠 O que é IA Generativa?
A IA generativa é um tipo de inteligência artificial capaz de criar novos conteúdos a partir de padrões aprendidos em grandes volumes de dados. Isso inclui textos, imagens, músicas, códigos e muito mais. Diferente de sistemas tradicionais que apenas respondem com base em regras fixas, a IA generativa inova e propõe soluções criativas, simulando a linguagem e o raciocínio humanos.
